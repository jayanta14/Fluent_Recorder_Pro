Official Policy

Privacy Policy

Last Updated: October 6, 2026 • Fluent Recorder Pro Chrome Extension

🛡️ Summary: Fluent Recorder Pro operates completely locally inside your browser. We do not collect, store, sell, or transmit any user data, browsing history, audio, or video streams to remote servers.

1. Introduction

Fluent Recorder Pro ("we", "our", or "the extension") is a lightweight browser extension designed to record desktop screens, application windows, tabs, and audio. We are deeply committed to user privacy and transparent practices.

2. Zero Data Collection

Fluent Recorder Pro does not collect any personal data or usage metrics. Specifically, we do not collect:

  • Personally Identifiable Information (name, email, IP address, etc.)
  • Browsing history, open tabs, or web activity
  • Keystrokes, mouse events, or analytics
  • Location data or device identifiers

3. Processing of Video & Audio Recordings

All video and audio recording features are executed purely in-memory on your local machine using standard HTML5 and Chromium APIs:

  • Display Media API (getDisplayMedia): Used exclusively to capture your chosen screen, window, or browser tab with your explicit confirmation.
  • User Media API (getUserMedia): Used solely to capture your microphone input when enabled by you.
  • Web Audio API: Used to combine and mix system and microphone audio streams locally.

Captured streams and finished video files (.webm) are never transmitted to external cloud servers. All recording processing stays strictly within your browser session.

4. Extension Permissions

Our extension requests only the minimum required permissions necessary to perform its core functions:

  • storage: Used locally to save your configuration preferences (e.g., FPS settings, preferred microphone device) and maintain local playback history in browser IndexedDB.
  • downloads: Used to save your completed video recording files directly to your device's Downloads directory upon stopping a recording.

5. Third-Party Services & Remote Code

Fluent Recorder Pro does not load any remote scripts, advertising tracking networks, or third-party analytics libraries. All application code is self-contained within the extension package.

6. Changes to This Policy

Any revisions to this privacy policy will be posted directly to this page with an updated revision date.

7. Contact

If you have any questions or feedback regarding this Privacy Policy or the security of Fluent Recorder Pro, please submit an issue or reach out via our Chrome Web Store developer listing page.
